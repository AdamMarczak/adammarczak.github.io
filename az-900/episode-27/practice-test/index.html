Practice Test

Question 1

Azure Key Vault service is designed to store what kind of information? Choose 3.

✔ That's correct
❌ That's not correct
👨‍🦱 💬 Azure Key Vault allows for secure storage of application secrets, encryption keys, and certificates.

Question 2

Encryption Keys are customer-managed keys that can be used to encrypt Virtual Machine disks. True or false?

✔ That's correct
❌ That's not correct
👨‍🦱 💬 This is true. Azure Disks can be encrypted using customer-managed keys with use of Azure Key Vault.

Question 3

If no encryption keys are provided by the customer, then by default Azure Disks are left unencrypted. True or false?

✔ That's correct
❌ That's not correct
👨‍🦱 💬 This is false. All disks are encrypted by default using Microsoft-managed keys unless the customer chooses to disable that.

Question 4

Application Secrets are typically …

✔ That's correct
❌ That's not correct
👨‍🦱 💬 All of the above. Anything that can potentially expose your services to potential unauthorized access or attacks can and should be stored as a secret.

Question 5

All web application configuration options should be stored in Azure Key Vault. True or false?

✔ That's correct
❌ That's not correct
👨‍🦱 💬 This is false. Azure Key Vault should be only used to store sensitive information. It is not designed to replace application configuration files, just compliment them by externalizing management of their sections which are considered sensitive.

Question 6

Which of the following services allows customers to monitor their Azure platform to provide security recommendations and analysis of potential threats

✔ That's correct
❌ That's not correct
👨‍🦱 💬 Azure Security Center provides a unified experience for securing Azure platforms by providing actionable recommendations and analysis of potential threats.
